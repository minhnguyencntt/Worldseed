# REQ · Pipeline generates nine-slice frame PNGs and the old frame, sound and pointer SVGs are gone

Context: ART_SOURCES holds only the hand cursor from the UI set. Desired: pure grid builder and FRAME_KIT registry producing 9 frames, registered in ART_SOURCES, generated by art:generate into public/assets/ui/frames with manifest entries; hand cursor kept. Expected: PNGs sized as declared using palette only. Why: frames for components.

## Acceptance criteria
- Given buildFrameGrid, when called with a spec, then the grid has the declared width and height and only palette indices
- Given FRAME_KIT, when listed, then it has bar, panel, plaque, parchment, slot, button-normal, button-hover, button-pressed and button-disabled with a slice smaller than half each dimension
- Given the committed manifest, when read, then each frame id has a PNG at the declared size
- Given game/public, when listed, then no svg named panel-frame, sound or pointer exists


## Scope
- In scope: src/art/uiFrames.ts
- In scope: sources.ts registration
- In scope: art:generate output
- Out of scope: room art
- Preserve: ui/cursor-hand
- Preserve: other art sources


## Technical constraints
- Deterministic script, no downloaded art
- Palette at most 48 colours
- Native 480x270 pixel scale


## Definition of done
- PNGs and manifest committed via art:generate
