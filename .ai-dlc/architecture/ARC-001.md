# ARC-001 — Documentation-only repository root

- Status: completed
## Boundary
The product surface is a flat git repository root with a single tracked documentation file. There is no modular application boundary, package graph, or service topology in source.

## Responsibilities
- Hold identity/greeting content in `README.md`
- Exclude Devion tooling paths from git via `.gitignore` (working tree; untracked at scan time)
- Defer all runtime, data, and UI boundaries: UNKNOWN until implementation appears

## Paths
| Path | Responsibility |
| --- | --- |
| `README.md` | Product greeting / identity text |
| `.gitignore` | Ignore `.devion/cache/`, `.devion/project.toml`, `.devion/local-env.toml`, `.devion/repos/`, `.devion/agents/`, `.devion/scans/`, `.devion/worktrees/`, `.devion/summary.md`, `.devion/summary-meta.json` |
| `.devion/project.toml` | Devion project metadata (`name = "workseed"`, `repos = ["main"]`) — tooling, not product module |
| `.devion/repos/main.toml` | Devion repo binding (path, remote, stub build/test cmds) — tooling, not product module |

## Non-boundaries (absent)
- Application layers, APIs, domain modules, infrastructure adapters: UNKNOWN / not present
