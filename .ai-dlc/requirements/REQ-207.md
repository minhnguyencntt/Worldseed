# REQ-207 — REQ · config.ts, createGame.ts and events.ts use only Phaser 3.90 APIs

## Summary
Game config, factory and event bus are 3.90-compatible and documented as such

## Description
Context: config.ts builds GameConfig with Phaser.AUTO, Phaser.Scale.FIT and render options. createGame.ts calls new Phaser.Game. events.ts has no Phaser dependency. Desired behavior: these modules use 3.90 equivalents only and state the 3.90 target. Expected result: no Phaser 4-only symbol appears in them. Why: protects the 3.90 pin.

## Acceptance criteria
- Given buildGameConfig, when called with a parent element and scenes, then it returns type Phaser.AUTO, width 640, height 360 and render.pixelArt true.
- Given createGame, when called with phaser mocked, then new Phaser.Game receives the config from buildGameConfig.
- Given events.ts, when its imports are read, then it imports nothing from phaser.

## Definition of done
- Modules carry a 3.90 target comment and use only 3.90 APIs
- Write/update persistent AI-DLC artifact `.ai-dlc/requirements/REQ-207.md`
