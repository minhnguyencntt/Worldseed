# REQ-074 — REQ · Approve, Retry and Reject 401 clear the token and show the gate with no stale action error

Each execution action's 401 reaches handleError, which clears the token and the action error state.

- Given actionError was set by a prior 500, when a 401 follows, then actionError and actionDetail are cleared.
