# INT-029 — SG-6.4.2 · Add onReject prop and Reject button to ExecutionPanel

## Summary
ExecutionPanel gets an optional onReject prop and a Reject button shown only while a run is AWAITING_APPROVAL

## Description
Context: game/frontend/src/components/ExecutionPanel.tsx already renders Approve (AWAITING_APPROVAL, onApprove) and Retry (FAILED, onRetry) and has no onReject. Desired behavior: add an optional onReject prop and a Reject button visible only for AWAITING_APPROVAL when onReject is given, calling onReject with the execution id. Expected result: Approve and Retry behave exactly as before. Why: the admin must be able to reject a publication (SG-6.4).

## Acceptance criteria
- Given status AWAITING_APPROVAL and onReject provided, when the panel renders, then a button named Reject is shown
- Given Reject is clicked, when onReject runs, then it is called once with the execution id
- Given onReject is not provided or status is not AWAITING_APPROVAL, when the panel renders, then no Reject button exists
- Given the change, when Approve or Retry is clicked, then they call onApprove or onRetry with the id as before

## Definition of done
- Reject button implemented per acceptance criteria
- Unit tests for the panel pass
- Write/update persistent AI-DLC artifact `.ai-dlc/intent/INT-029.md`
