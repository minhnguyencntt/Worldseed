# INT-001 — Repository identity greeting

## What it is for
Establish the repository’s public name and greeting. At tip, this is the only product-facing capability: `README.md` communicates `hello Worldseed` to anyone cloning or browsing the repo.

## Who uses it
- Repository readers / contributors who open `README.md`
- Other actors (end users of an application, operators, API clients): UNKNOWN — no such surfaces exist in code

## Out of scope (not evidenced)
- Application features, APIs, persistence, auth, UI, or runtime workflows — UNKNOWN / absent from tip
